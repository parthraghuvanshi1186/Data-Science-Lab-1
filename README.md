# FIFA World Cup 2026 Player Performance Analysis

## Overview

This project analyzes the FIFA World Cup 2026 Player Performance Dataset using Python and Pandas. The dataset contains 54,600 player performance records and 75 features, including player statistics, match performance, physical attributes, offensive and defensive contributions, and tournament ratings.

## Objectives

* Explore and understand player performance data.
* Perform data cleaning and preprocessing.
* Analyze key performance metrics.
* Generate statistical insights from the dataset.
* Identify trends in player and team performances.

## Dataset Information

* Total Records: 54,600
* Total Features: 75
* Data Types: Numerical and Categorical
* Tools Used: Python, Pandas, NumPy

## Technologies Used

* Python
* Pandas
* NumPy
* Jupyter Notebook

## Analysis Performed

* Dataset loading and inspection
* Exploratory Data Analysis (EDA)
* Statistical summary generation
* Missing value inspection
* Player performance evaluation
* Tournament statistics analysis

## Key Features in Dataset

* Player Information
* Team Details
* Match Statistics
* Goals and Assists
* Passing Accuracy
* Defensive Actions
* Physical Performance Metrics
* Tournament Ratings
* Performance Scores

## Results

The analysis provides insights into player contributions, performance ratings, offensive and defensive effectiveness, and overall tournament impact.
